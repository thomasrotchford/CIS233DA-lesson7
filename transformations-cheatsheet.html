Terminology

Animations
Animations allow elements on a webpage to change or move over time without needing someone to interact with them.
Keyframes
Keyframes are used to set the different stages of an animation and control how an element changes during those stages.
Transforms
Transforms allow you to change the appearance of an element by moving, rotating, resizing, or tilting it.
Transitions
Transitions make changes between CSS property values happen smoothly instead of changing instantly.
Easing
Easing controls how fast or slow an animation or transition moves at different points.
Rotation
Rotation turns an element around a point by a certain number of degrees.
Scale
Scale changes the size of an element, making it larger or smaller.
Skew
Skew tilts or slants an element horizontally or vertically.
Delay
Delay controls how long an animation or transition waits before starting.
Transition Timing
Transition timing controls how the speed of a transition changes from the beginning to the end.
