Terminology

Animations
Make elements move or change over time.
Keyframes
Set the steps of an animation.
Transforms
Change an element's size, position, or angle.
Transitions
Make changes happen smoothly.
Easing
Controls how movement speeds up or slows down.
Rotation
Turns an element around a point.
Scale
Makes an element bigger or smaller.
Skew
Slants an element.
Delay
Sets how long to wait before starting.
Transition Timing
Controls how speed changes during a transition.

Transition Properties

transition-property

Chooses what changes.

.box {
    transition-property: background-color;
    transition-duration: 1s;
}

.box:hover {
    background-color: yellow;
}
Property Preview

transition-duration

Sets how long a change takes.

.box {
    transition: transform 2s;
}

.box:hover {
    transform: translateX(20px);
}
Duration Preview

transition-timing-function

Controls the speed of a change.

.box {
    transition: transform 2s;
    transition-timing-function: ease;
}

.box:hover {
    transform: translateX(20px);
}
Timing Preview

transition-delay

Waits before a change starts.

.box {
    transition: transform 2s;
    transition-delay: 1s;

Animation Properties

@keyframes

Sets the steps of an animation.

@keyframes move {
    from { left: 0; }
    to { left: 50px; }
}

.box {
    position: relative;
    animation: move 2s;
}
Keyframes Preview

From and To

Sets the start and end.

@keyframes fade {
    from { opacity: 0; }
    to { opacity: 1; }
}

.box {
    animation: fade 2s;
}
From and To Preview

Percentages

Sets steps using percentages.

@keyframes grow {
    0% { transform: scale(1); }
    50% { transform: scale(1.5); }
    100% { transform: scale(1); }
}

.box {
    animation: grow 2s;
}
Percent Preview
